# IBM BOB

IBM BOB is a small repository used to generate onboarding documentation for a codebase using IBM Bob.

## What this project contains
- `bob_sessions/`: exported Bob task history and screenshots.
- `outputs/`: generated documentation files.

## Generated docs
- `outputs/architecture.md`
- `outputs/modules.md`
- `outputs/onboarding.md`

## Purpose
This project helps new developers understand a repository quickly by turning Bob analysis into clear documentation.

## Workflow
1. Ask Bob to analyze the repository.
2. Save the results in `outputs/`.
3. Export Bob session history into `bob_sessions/`.
